# Намаз — дизайн для реализации (React Native, Expo SDK 54)

Живой макет: https://claude.ai/artifact/MJevhF76Z5Foe6M6gPCa73
Экраны: Главная, Коран, Кибла, Настройки, Загрузка, Иконка. Токены — `theme.ts`, иконки — `assets/`.

## Принципы
- Тёмная тема, один акцент — золото `#E3BE72`. Никаких синих, фиолетовых и зелёных акцентов.
- Фирменный мотив — вложенные арки (михраб). Он есть в карточке «Фаджр», на экране «Коран», в иконке.
- Без градиентов, свечений и теней. Глубина только цветом слоёв и тонкими рамками 1 px.
- Шрифты: Manrope (интерфейс), Cormorant Garamond (слоганы, аяты), Amiri (арабский).
- Цифры времени всегда с `fontVariant: ['tabular-nums']`.
- Касание не меньше 44×44.

## Библиотеки
`react-native-svg` (арки, компас, иконки), `expo-font` + `@expo-google-fonts/{manrope,cormorant-garamond,amiri}`,
`expo-sensors` (Magnetometer для компаса), `expo-location`, `expo-splash-screen`, `@react-navigation/bottom-tabs`.
Иконки интерфейса — линейные, stroke 1.8, скругление `round` (подойдёт `lucide-react-native`).

## Общие компоненты
- **Нижняя панель** (5 вкладок: Главная, Коран, Кибла, Карта, Ещё): высота 76, фон `navBg`, сверху рамка `borderSoft`. Активная вкладка — `accent`, bold; остальные — `muted`. Иконка 24, подпись 11.
- **Шапка раздела** (Коран, Кибла): слева заголовок 28 bold, справа чип города (высота 44, рамка `border`, радиус 14, пин `accent`, шеврон) и кнопка «i» 44×44.
- **Карточка**: фон `surface`, рамка `border`, радиус 22.
- **Строка списка**: высота 54–64, радиус 18, рамка `borderSoft`, без заливки. Выделенная строка: фон `surfaceActive`, рамка `accent`.
- **Пилюля**: радиус 999, фон `bg`, рамка `borderStrong`, точка 8 px `accent` слева.

### Настройки
Заголовок со стрелкой назад. Секции «Общие», «Местоположение», «Намаз»: подпись label `accent`, под ней строки по 64 (плашка иконки 40 `surfaceActive`, заголовок 16 semibold, подпись 13 `muted` с `ellipsizeMode`, шеврон). «GPS-позиция» неактивна (opacity 0.5). Внизу пояснение 13 `muted`.

### Загрузка
Фон `bg`: небольшой полумесяц `#1B2F28` над текстом, звёздные точки (`muted`/`accent`, 1–1.5 px) и золотые «блески» (4-лучевые). По центру «نماز» (Amiri 150, `accent`), «НАМАЗ» (Manrope 800, 36, letterSpacing 0.34 em), слоган (Cormorant 22), «ВРЕМЯ МОЛИТВЫ · КОРАН · КИБЛА» (12, `muted`). Внизу: 5 точек (Ф З А М И) с линиями между ними, пройденные этапы золотые, дальше пустые; под ними «Синхронизация времени молитв…» (13, `muted`). Этапы загрузки = закрашенные точки.

### Иконка
`assets/icon.png` (1024, без скруглений, маску применяет система), `assets/adaptive-icon-foreground.png` для Android. Фон иконки `#0F1B17`.

```json
// app.json (фрагмент)
{
  "expo": {
    "icon": "./assets/icon.png",
    "android": { "adaptiveIcon": { "foregroundImage": "./assets/adaptive-icon-foreground.png", "backgroundColor": "#0F1B17" } },
    "plugins": [["expo-splash-screen", { "image": "./assets/adaptive-icon-foreground.png", "backgroundColor": "#0D1613", "imageWidth": 200 }]]
  }
}
```
Нативный сплэш показывает иконку на `#0D1613`; затем открывается экран «Загрузка» как обычный React-компонент, и после синхронизации скрывается `SplashScreen.hideAsync()`.
